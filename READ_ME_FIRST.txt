LoadoutRoom - version 1.0.18

Extract the entire ZIP and open LoadoutRoom.exe.
Keep the app and runtime folders beside it. Python is included.
Open VALORANT and join a match, or use Show sample for an offline preview.

This release renames the application to LoadoutRoom, including the window,
header, dialogs, executable and Windows file properties.
LoadoutRoom1.0.exe is included only for compatibility with older updaters
and shortcuts. Both filenames open the same application.

Updates: use Updates > Save and check. Each installation asks permission.
The release feed remains thatguyforgotten-design/LoadoutRoom on GitHub.

Source is in app/ and source/. Original and dependency licenses are included.
